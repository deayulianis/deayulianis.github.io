Travel Shantuy(December 2024 - January 2025)

Web Programming Project - Gunadarma University

This project is a group assignment for the Web Programming course, where we developed a travel and culinary catalog website. The website showcases various tourist destinations, local foods, detailed descriptions, and recommended places. I contributed to the user interface design in Figma and implemented several key UI components on the website.

📑 Main Features

  • Travel Catalog
      • ➡️ List of tourist attractions
      ➡️ Destination details page
      ➡️ Photos and Locations of Tourist Attractions
  • Culinary Catalog
      • ➡️ List of regional culinary delights
      ➡️ Food description & where to buy
  • Recommendation
      • ➡️ Culinary and tourism that are recommended because they are popular

    💁‍♀️ Team Contribution

    • In this project, I contributed to :

    🎯 Results

    • The website successfully presents a responsive travel and culinary catalog with an attractive and intuitive interface. Users can explore detailed information, photos, and recommendations, while the search & filter feature helps them find destinations easily.
