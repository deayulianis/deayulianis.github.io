WasteWise AI (April 2025 – June 2025)

Capstone Project — Coding Camp powered by DBS Foundation 2025

A collaborative capstone project from The Coding Camp powered by DBS Foundation 2025, integrating Front-End, Back-End, and Machine Learning Development. The system classifies 3 types of waste: organic, inorganic, and hazardous (B3) .Using an image classification model built with Convolutional Neural Network (CNN). The trained model was later integrated into the team's WasteWise AI website to provide automated waste detection.

📊 Datasets

  • Three waste categories (organic, inorganic, B3) collected from various open image sources and manual curation.
  • Approximately 7,182 images used for training, validation, and testing.

🛠️Tools & Libraries

🧩 Project Stages

  • Data collection and cleaning.
  • Image preprocessing (resizing, augmentation, normalization).
  • Building and training the CNN model for three-class classification.
  • Model evaluation using matrix and accuracy metrics.
  • Saving the trained model (.h5) for website integration.

🎯 Results

  • Can detect 3 types of waste and 15 categories of waste
  • Achieved Training Accuracy of 100% and Validation Accuracy of 87.68%.
  • Average F1-Score: 0.83, showing balanced performance across all classes.
  • The trained model was successfully integrated into the WasteWise website for automatic waste image classification.
