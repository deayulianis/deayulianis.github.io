Smart Skincare Application (April 2025-July 2025)

Scientific Writing Project — Gunadarma University

A machine learning–based application that uses a Convolutional Neural Network (CNN) model to classify seven types of facial skin problems from images. The system also provides personalized skincare product recommendations using a content-based filtering approach, integrated with a simple and user-friendly Streamlit interface.

📊 Datasets

  • Facial Skin Problem Dataset: 2,450 images collected through web scraping from Google Images, Pinterest, and medical sites like DermNet.
  • Skincare Product Dataset: Over 700 skincare products scraped from Sociolla and BeautyHaul.

🛠️ Tools & Libraries

🧩 Project Stages

  • Performed web scraping for image and product data collection.
  • Conducted data preprocessing: augmentation, resizing, and normalization.
  • Built and trained CNN model for classifying seven facial skin problem categories.
  • Evaluated model using confusion matrix and accuracy score.
  • Developed content-based product recommendation system based on classification results.
  • Implemented interactive Streamlit interface to display classification and recommendations.

🎯 Results

  • The CNN model was trained to recognize seven categories of facial skin problems with stable performance.
  • Can detect 7 skin problems and provide product recommendations
  • Achieved Training Accuracy 93.97%, Validation Accuracy 80.20%, and Test Accuracy 79.76%.
  • Average model performance: Precision 0.82, Recall 0.81, and F1-Score 0.81.
  • Best performing categories: Signs of Aging (F1 = 0.94) and Sensitive or Irritated Skin (F1 = 0.89).
  • Lowest performing category: Dry or Dehydrated Skin (F1 = 0.59).
  • Overall, the model demonstrated good generalization with no significant overfitting.
