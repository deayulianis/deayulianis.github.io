Diabetes Prediction (May 2025 - June 2025)

Applied Machine Learning Project— Coding Camp powered by DBS Foundation 2025

This project aims to build a diabetes prediction model using three machine learning algorithms: Logistic Regression, Random Forest Classifier, and XGBoost Classifier. Each model is compared to find the algorithm with the best performance in predicting whether a patient is at risk for diabetes (positive) or not (negative).

📊 Datasets

  • Used Pima Indians Diabetes Databases from Kaggle, which has 100,000 rows and 9 columns
  • Variables in the Dataset: gender, age, hypertension, heart_disease, smoking_history, bmi, HbA1c_level, blood_glucose_level, diabetes.
  • This dataset allows the model to study the relationship between medical factors, lifestyle, and diabetes risk in thousands of patients.

🧰 Tools & Libraries

🧩 Project Stages

  • Business Understanding
  • Data Understanding : statistical exploration (mean, median, distribution), checking for missing values, outlier visualization (e.g. in the BMI and glucose columns), correlation analysis between features for diabetes.
  • Data Preparation : Encoding, Scaling, Train–Test Split.
  • Modeling : Logistic Regression, Random Forest Classifier, XGBoost.
  • Model Evaluation : Accuracy score, F1-score, Model comparison chart.

🎯 Results

  • Machine Learning model successfully built.
  • Best model found (XGBoost).
  • The most influential factors on diabetes: Blood glucose level, HbA1c level, BMI, Age, Smoking history.
  • The model can predict new patients
