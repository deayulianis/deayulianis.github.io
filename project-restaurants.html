Restaurant Management Website for Client “Ibu Tami” (October 2025 – Present)

Software Processing Project — Gunadarma University

This project was developed for a real client, Mrs. Tami, who manages a small restaurant. She needed a system that could help streamline menu management, order processing, inventory tracking, and sales reporting. As the system analyst, I designed the system requirements, workflows, and proposed the website architecture.

💁‍♀️ Client Needs

  • Menu Management Still Using WhatsApp.
  • Manual order.
  • No automated sales report.
  • No real-time ingredient stock monitoring..

🛠️Tools & Technologies

🧩 Project Goals

  • Building an easy-to-use restaurant website.
  • Simplifying menu management (CRUD).
  • Automating order recording.
  • Providing daily/monthly sales reports.
  • Monitoring ingredient inventory in real time.

🎯 Results

  • Software Requirements Specification (SRS)
  • Use Case Diagram & Use Case Description
  • Activity Diagram (Menu, Order, Inventory, Sales Report)
  • ERD (Entity Relationship Diagram)
  • Database Schema
