Image Classification Using Convolutional Neural Network(May 2025)

Deep Learning 2 Project — Coding Camp powered by DBS Foundation 2025

This project focuses on building a Convolutional Neural Network (CNN) model to classify images into six landscape categories: buildings, forest, glacier, mountain, sea, and street. The dataset used is the Intel Image Classification Dataset from Kaggle. The project covers the full pipeline: data preparation, augmentation, CNN modeling from scratch, training, evaluation, and exporting the model to TensorFlow Lite and TensorFlowJS for mobile and web deployment.

📊 Datasets

  • The dataset comes from Kaggle - Intel Image Classification Dataset
  • Contains 25,000+ images across 6 classes.

🛠️ Tools & Libraries

🧩 Project Stages

  • Data Preparation :
      • ➡️ Download dataset using Kaggle API.
      ➡️ Merge training + testing folders into one directory.
      ➡️ Avoid filename collisions.
      ➡️ Split into train / validation / test (70/15/15).
  • Data Preprocessing:
      • ➡️ Resize images to 150×150 px.
      ➡️ Normalize pixels
      ➡️ Simple augmentation: rotation, rescaling
  • CNN Modeling :
      • Architecture:
      ➡️ 4 blocks of Conv2D + MaxPooling.
      ➡️ Flatten → Dense → Dropout.
      ➡️ Softmax output for 6 classes.
      Loss : Categorical Crossentropy
      Optimizer : Adam
  • Training :
      • ➡️ 15 epochs.
      ➡️ Batch size 32.
      ➡️ Real-time monitoring on validation accuracy.
  • Evaluation :
      • ➡️Train Accuracy : 94.87%.
      ➡️Test Accuracy : 85.01%.
      ➡️Includes accuracy/loss curves, confusion matrix, classification report.
  • Model Export :
      • Model exported into :
      ➡️ SavedModel.
      ➡️ TensorFlow Lite (.tflite) for mobile usage.
      ➡️ TensorFlowJS for web deployment.

🎯 Results

  • Performance
      • ➡️ CNN model achieved 85% accuracy on the test set.
      ➡️ Best-performing class: forest.
      ➡️ Most challenging pairs: glacier vs mountain, street vs buildings.
  • Visualization Insights
      • ➡️ Stable training without significant overfitting.
      ➡️ Confusion matrix reveals class similarity as main source of error.
  • Deployment Ready
      • ➡️ Successfully exported to TFLite & TFJS
      ➡️ Ready for integration with: Mobile apps, Web apps, Edge-device inference
