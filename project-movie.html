Movie Recommendation System (June 2025)

Applied Machine Learning Project 2 — Coding Camp powered by DBS Foundation 2025

A personalized movie recommendation system built using two main approaches: Content-Based Filtering and Collaborative Filtering (SVD). The model suggests movies that align with user preferences by analyzing both movie metadata (genre) and user rating patterns.

📊 Datasets

  • Used the MovieLens dataset from Kaggle, containing information on 9,742 movies and 610 unique users.
  • Includes movie metadata (title, genres), user ratings, and tags.
  • Total of 100,836 ratings and 3,683 tags used to train and evaluate the recommendation models.
